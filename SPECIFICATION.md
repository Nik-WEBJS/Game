# Business Tycoon — Спецификация реализации (MVP)

## Обзор

Пошаговая веб-игра в жанре бизнес-тайкуна. Игрок управляет компанией, комбинируя нишу, продукт, технологии, команду, стратегию монетизации и стандарты ISO. Цель — построить устойчивый и прибыльный бизнес, избежав банкротства и потери репутации.

**Стек:** Next.js 16, React, TypeScript, TailwindCSS, Zustand, Lucide Icons

---

## Архитектура

```
UI (React Components)
 └─ Game Controller (Zustand Store)
     ├─ Time Engine        — пошаговый цикл (1 ход = 1 неделя)
     ├─ Business Engine    — расчёт экономики (доход, расходы, прибыль)
     ├─ Combination Engine — коэффициенты: ниша × продукт × технологии × рынок × ISO
     ├─ ISO Engine         — жизненный цикл ISO 9001 (5 стадий)
     ├─ Event Engine       — случайные события на основе метрик
     ├─ Team Engine        — найм, увольнение, выгорание, мораль, опыт
     └─ Progression Engine — опыт игрока, репутация, условия победы/поражения
```

## Реализованные игровые сущности

### Игрок (Player)
| Поле | Тип | Описание |
|------|-----|----------|
| `money` | number | Текущий баланс (старт: $50,000) |
| `reputation` | number | 0–100, влияет на события и условия победы |
| `experience` | number | Накопленный опыт |
| `currentWeek` | number | Текущая неделя (номер хода) |

### Бизнес (Business)
| Поле | Тип | Описание |
|------|-----|----------|
| `nicheId` | string | Выбранная ниша |
| `productId` | string | Выбранный продукт |
| `monetizationId` | string | Стратегия монетизации |
| `technologies` | string[] | Внедрённые технологии |
| `marketId` | string | Текущий рынок |
| `team` | TeamMember[] | Команда сотрудников |
| `isoStandards` | ISOStandard[] | Стандарты ISO |
| `metrics` | BusinessMetrics | Текущие метрики |

### Метрики бизнеса (BusinessMetrics)
- **revenue** — доход за неделю
- **costs** — расходы (зарплаты + инфраструктура + ISO + сложность технологий)
- **profit** — чистая прибыль
- **risk** — уровень риска (0–1)
- **quality** — качество продукта (0–1)
- **demand** — спрос (0–1)
- **growthRate** — темп роста
- **teamEfficiency** — эффективность команды (0–1)

## Реализованные движки (Engines)

### Combination Engine
Формула комбинации:
```
CombinationResult =
  BaseNicheValues
  × ProductFit
  × TechSynergy
  × MarketModifier
  × ISOModifiers
```
- Синергия технологий: +10% за каждую пару совместимых технологий
- Комбинации не жёсткие — через коэффициенты

### Economy Engine (Формулы)

**Доход:**
```
Revenue = Demand × Quality × MonetizationEfficiency × TechSynergy × BASE_SCALE($50,000)
```

**Расходы:**
```
Costs = TeamSalaries + Infrastructure(10% от стоимости технологий) + ISOMaintenance + TechComplexityCost
```

**Риск:**
```
Risk = BaseComplexity×0.3 + TotalTechComplexity×0.5 + GrowthAggression + TeamLoad×0.3 + MonetizationRisk − ISOStabilization
```

**Эффективность команды:**
```
TeamEfficiency = (AvgExperience/100) × ProcessQuality(менеджер: 1.15) × ISOSupport(серт: 1.1) × (1 − AvgBurnout/150)
```

### ISO Engine
Жизненный цикл ISO 9001 (5 стадий):

| Стадия | Стоимость | Недель на завершение |
|--------|-----------|---------------------|
| Audit | $3,000 | 2 |
| Implementation | $8,000 | 4 |
| Internal Check | $4,000 | 2 |
| Certification | $6,000 | 3 |
| Maintenance | $2,000/нед | ∞ |

- Прогресс: 25 + (QA: +10) + (Менеджер: +8) за ход
- В maintenance: 5% шанс проблемы каждый ход
- ISO = стабилизатор, НЕ баф к деньгам

### Event Engine
14 событий в пуле, 5 типов:

| Тип | Количество | Примеры |
|-----|-----------|---------|
| Market | 3 | Бум рынка, Спад, Новый конкурент |
| Internal | 2 | Конфликт в команде, Искра инноваций |
| Crisis | 3 | Утечка данных, Сбой серверов, Штраф регулятора |
| Positive | 3 | Вирусный рост, Публикация в СМИ, Магнит талантов |
| ISO | 2 | Внеплановый аудит, Награда за качество |

- Вероятность: ~60% — 1 событие, ~20% — 2 события, ~20% — нет событий
- Взвешенный случайный выбор
- Условия: зависят от метрик, команды, технологий, ISO-статуса
- Сертифицированный ISO блокирует 50% кризисных событий

### Team Engine
5 ролей:

| Роль | Зарплата/нед | Стоимость найма | Особенности |
|------|-------------|-----------------|-------------|
| Developer | $4,000 | $8,000 | +1 доп. опыт/ход |
| Manager | $3,500 | $7,000 | +15% эффективность процессов, +8 прогресс ISO |
| QA | $3,000 | $6,000 | +10 прогресс ISO |
| Security | $3,800 | $7,600 | — |
| Marketing | $3,200 | $6,400 | Открывает событие "Вирусный рост" |

- **Выгорание:** растёт от риска, снижается от морали и ISO
- **Мораль:** зависит от прибыли и выгорания
- **Опыт:** +1–2 за ход
- **Авто-увольнение:** при выгорании ≥ 95

### Progression Engine
**Условия поражения:**
- Банкротство (баланс ≤ −$50,000)
- Репутация = 0

**Условия победы (soft-win):**
- IPO: баланс ≥ $500,000 и репутация ≥ 80
- Доминирование: репутация ≥ 95 и качество ≥ 90%

**Прогрессия:**
- Опыт: +5 + (прибыль / $5,000) за ход
- Репутация: дрейфует на основе качества и прибыли
- Тренды ниш: спрос медленно снижается каждый ход

## Пошаговый цикл (1 ход = 1 неделя)

1. Увеличение номера недели
2. Тик команды (опыт ↑, выгорание, мораль, авто-увольнения)
3. Тик ISO (прогресс стадий, проверка maintenance)
4. Расчёт экономики (доход, расходы, прибыль → баланс)
5. Бросок и применение событий
6. Начисление опыта и дрейф репутации
7. Старение трендов (снижение спроса ниши)
8. Запись истории метрик
9. Проверка условий победы/поражения

## UI (Интерфейс)

### Экраны
1. **Setup Screen** — выбор ниши, продукта, монетизации, технологий → запуск
2. **Game Dashboard** — основной игровой экран с вкладками
3. **Game End Screen** — экран победы/поражения со статистикой

### Вкладки Dashboard
- **Обзор** — метрики бизнеса + журнал событий + информация о бизнесе + быстрая статистика
- **Команда** — найм/увольнение, прогресс-бары опыта/выгорания/морали
- **Технологии** — внедрение/удаление, синергии, стоимость
- **ISO** — стадии, прогресс, эффекты, действия
- **Журнал** — полный лог событий

### Top Bar
- Название игры, неделя, баланс, репутация, опыт, прибыль/нед, переключатель языка

## Локализация (i18n)

- **Языки:** English (EN), Русский (RU)
- **Переключатель:** кнопка-глобус в TopBar, SetupScreen и GameEndScreen
- **Система:** Zustand store (`useI18n`), ~200 ключей перевода
- **Покрытие:** все UI-строки, названия/описания сущностей, события, роли, стадии ISO
- **Переключение:** мгновенное, без перезагрузки страницы

---

## Не реализовано (за пределами MVP)

- Мультиплеер
- Несколько стандартов ISO
- Рынки с требованиями (ISO-гейтинг)
- Инвесторы
- M&A (слияния и поглощения)
- Эпохи
- AI-советник
- Визуальные эффекты / анимации
- Сложные цепочки ISO
- Сохранение прогресса (localStorage / БД)
